# Peripheral examples

Short examples that each use **one** peripheral on its own, such as a button,
the MP3 player, an LED strip or a servo. Start here to learn how a peripheral
works before combining it with others in a toy (see `examples/toys`).

To run one, copy it to the Pico's CIRCUITPY drive and rename it `code.py`.

When adding an example here:

- Name it after the peripheral, like `servo_example.py`.
- At the top, list the pins it uses and how to wire them.
- Keep it short. Use only the one peripheral, plus a button if it needs a
  trigger.
